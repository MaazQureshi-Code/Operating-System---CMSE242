# 🖥️ CMSE242 – Operating Systems 

## 📘 Course
**CMSE242 – Operating Systems**  
**Eastern Mediterranean University (EMU)**

## 📝 Project Description
This is CMSE242 Operating Systems course. It focuses on implementing key OS concepts including process scheduling, memory management, and **synchronization mechanisms** such as semaphores and mutexes to manage concurrent processes. and it is c language

The objective is to gain practical experience with system-level programming and understand how operating systems ensure safe and efficient execution of multiple processes.

## 🧠 Topics Covered
- Process Management
- Scheduling Algorithms (e.g., FCFS, Round Robin)
- Memory Management (Paging, Segmentation)
- **Process Synchronization** (Semaphores, Mutexes)
- Inter-process Communication (Pipes, Shared Memory)
- File System Basics
